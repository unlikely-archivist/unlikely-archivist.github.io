Obsidian tool · Templater

Flatpack

Turn a tangled Obsidian vault into one clean, portable document—without copying the same embedded note over and over.

The problem

Obsidian’s Easy Bake plugin merges a vault’s notes into one document, but heavily cross-embedded notes can echo throughout the result. Shared content gets duplicated until the master document is too bloated to be useful.

The smarter approach

Flatpack keeps the first copy of an embedded note, replaces repeats with a one-line pointer, and turns the original folder structure into a readable heading hierarchy.

104,000 → 9,700lines in a real test vault, by keeping one copy of each repeated note.

Autonomous publication · Val Town · TypeScript

RIP · URL

A weekly obituary for dead websites—written by a machine held to an archivist’s rules.

The risk

Left unsupervised, an AI writer can choose a living company, fill gaps from memory, or turn guesses into confident history. For a publication about real companies, “usually right” isn’t good enough.

The system

A TypeScript state machine discovers a candidate, checks that its URL is really dead, assembles primary evidence and an archived screenshot, then independently fact-checks every draft before publication. Automated tests, run on every push, guard the rule that matters most: a website that’s still alive never gets an obituary.

discover → vet → evidence → screenshot → write → verify → publish

Bluesky scheduler · Cloudflare Workers · Vision AI

crierbaby

A self-hosted photo scheduler that drafts captions from the photo itself—and never posts anything you haven’t approved.

The problem

Posting a photo every day is a chore, but handing the account to an AI means off-voice, repetitive, or wrong posts can go out with no one checking.

The system

A vision model drafts captions and alt text, similar-looking photos get spaced apart, and new captions are checked for repetition. Plain-language notes set the voice. Nothing publishes until it’s approved. Automated tests cover the parts that fail quietly: a retry that never posts twice, a schedule that survives daylight saving, look-alike photos, repeated phrases, and PIN rate limits.

stash → caption → approve → schedule → post
