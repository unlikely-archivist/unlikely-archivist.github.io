Projects

RIP · URL TypeScript · Val Town · LLM APIs

An autonomous weekly publication (ripurl.val.run). A state machine finds a dead website, proves the URL is dead, gathers primary evidence and an archived screenshot, writes the obituary, and independently fact-checks every draft before it publishes.

crierbaby JavaScript · Cloudflare Workers · vision AI

A self-hosted Bluesky photo scheduler. A vision model drafts captions and alt text, similar photos are spaced apart, new captions are checked for repetition, and nothing posts without approval.

Flatpack JavaScript · Obsidian Templater

Merges an Obsidian vault into one document, replacing repeated embeds with one-line pointers. Cut a real 104,000-line export to 9,700 lines with nothing lost.

Creative Browser Tools JavaScript · Canvas

A palette maker that pulls colors from a photo, and an image degrader that simulates resampling, color reduction, chroma bleed, and JPEG generation loss.
